# Transcripts

Plain-text Whisper transcripts, one per episode, named to match `content/episodes/` (e.g. `22-bleeding-icu.txt`).

Written by `scripts/new-episode-prep.mjs` when you run `/new-episode` in Claude Code. They are the source material for each episode's essay, chapters and Q&A, and are committed alongside the episode page so they can later be published as a transcripts section.

Automatic transcripts: expect the odd mangled drug or device name.
